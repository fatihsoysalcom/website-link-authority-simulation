# Website Link Authority Simulation

This Python script simulates how 'link authority' or 'PageRank' flows through a network of websites. It demonstrates that links from high-authority and relevant sources contribute significantly more to a target site's authority than links from low-quality or irrelevant sites, reflecting modern SEO principles.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`.
